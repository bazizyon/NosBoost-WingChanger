# Wing Changer

A NosBoost mod that lets you wear any wings you want on your specialist card. Only you see the change.

## What it does

- Pick any wing design and upgrade level and wear it.
- Save a wing's images to a folder, edit them, and load them back as your own design.
- Your own designs are added after the game's designs, so you can keep as many as you want.
- Stop puts your real wings back.

Wings are saved in `mods\WingChanger\Wings\`.

## Install

Download the DLL from this repo's Releases and put it in the game's `mods` folder. NosBoost loads it by itself. Open it from the NosBoost mods menu (F9).
